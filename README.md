# `dsh-context-presets`

**为 DeepSeek Harness 的每个模型单独设定上下文窗口。**

DSH 用模型的上下文窗口做预算与溢出判断。本插件把这件事收敛成一个入口：右键输入框下方的窗口芯片换档，或在设置弹窗里逐个模型精调。所有取值写入 `llm-pi-ai` 命名空间，由宿主校验与持久化，改动即时生效、无需重启。

> 只调整 DSH 侧的预算基准，**不扩大服务商的真实上限**。自定义值不会超过上游声明的窗口。

## 为什么

同一模型经由不同渠道挂载时真实窗口常常不同，而安装目录给的是保守值；也有人想反向调小窗口，让 DSH 更早压缩。插件把「按模型改窗口」做成一个不依赖第三方插件的小面板。

## 功能

| 能力 | 说明 |
| --- | --- |
| 左键状态面板 | 点窗口芯片弹出面板：当前值、上游默认值、横向档位、自定义输入框 |
| 右键档位菜单 | 右键芯片弹出与系统右键菜单同款的列表，换档一步到位 |
| 跟随上游 | 档位之一：不写死数值，DSH 使用上游声明的窗口，上游变了就跟着变 |
| 自定义 | 面板输入框直接填任意正整数，上限由上游声明决定 |
| 设置弹窗 | 按提供方 / 模型列出，标出已自定义与已调整档位的模型，可只看已自定义 |
| 批量 | 按提供方一次性应用或恢复，超出上游的模型自动跳过 |
| 界面刷新 | 右键菜单与设置弹窗内置，不关闭客户端即可重载界面 |

## 安装

```sh
dsh plugin --profile web add dsh-context-presets
```

## 架构

- `src/core` 纯逻辑：档位、设置文档读取、写入计划、菜单条目；
- `src/client` 界面：窗口芯片、右键菜单、设置弹窗，经核心槽位 `conversation.composer.dock` 与 `plugins.bundle.config` 挂载；
- `src/host` 宿主半侧，只占位、不持有状态；
- `build.mjs` 把这些模块内联成浏览器可执行的 `lib/client.js`，`lib/index.js` 是宿主入口。

## 兼容性

DSH ≥ 0.2.0-rc.2，Web 客户端。
